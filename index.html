About webERP

Open Source ERP Software for Modern Business Management

webERP is a complete web-based open-source accounting, business management and ERP (Enterprise Resource Planning) system built for businesses of all sizes. Unlike expensive proprietary ERP systems, webERP is free, flexible, and fully customizable.

Why Choose webERP?

  • 100% Free & Open Source — GNU Public License v2. No licensing fees, no hidden costs.
  • Web-Based — Access from anywhere using any modern browser. No software installation required.
  • Easy to Customize — Written in readable PHP code with clear coding standards. Modify it to fit your unique business needs.
  • 20+ Years of Development — Battle-tested and continuously improved by a dedicated community.
  • Multi-Language Support — Available in 37 languages for global businesses.
  • Comprehensive Features — Inventory management, accounting, business administration, and more.

Ideal For: Small to medium-sized businesses in manufacturing, distribution, wholesale, hospitality, and healthcare sectors.

Ready to get started? Explore our complete feature list, read the user guides, or try the live demo to see webERP in action. No installation or registration required.

webERP is provided according to the terms of the GNU General Public License v2. As of 01/01/2026 the current release of webERP is v5.0.1 for PHP v8.

webERP has been in active development and use for more than 20 years. The project was started by Phil Daintree and is now led by Tim Schofield, both qualified accountants, whose guiding principal has been to make webERP easy for business people to use and modify.

The webERP project also maintains webSHOP, an add-on eCommerce portal, and CounterLogicPOS, an add-on Point Of Sale portal. Use them individually or together to create a dispersed multi-branch retail management system.

This webERP project website is also open-source. You can fork weberp.org on GitHub and send a pull request with additions and improvements (please first post your ideas in a Discussions topic).
